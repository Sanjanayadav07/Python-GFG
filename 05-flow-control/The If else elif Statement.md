# Python Conditional Statements (if / elif / else)

This file contains **three Python programs** based on conditional statements.

---

## Program 1: Big or Number

```python
n = int(input("Enter a number: "))

if n > 100:
    print("Big")
print("Number")
```
---

## Program 2: Number or Big
```python
a = int(input("Enter a number: "))

if a <= 100:
    print("Number")
else:
    print("Big")
```

## Program 3: Big, Small or Number
```python
a = int(input("Enter a number: "))

if a > 100:
    print("Big")
elif a < 10:
    print("Small")
else:
    print("Number")
```
