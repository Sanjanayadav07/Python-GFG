## ➕➖✖️➗ Basic Arithmetic Operations in Python

### 📌 Problem Statement
You are given two integers `x` and `y`.  
Perform the following operations:

1. Addition (`x + y`)
2. Subtraction (`x - y`)
3. Multiplication (`x * y`)
4. Integer Division (`x // y`)
5. Modulo (`x % y`)

Print all results in a **single line**, space-separated.

---

### ⏱ Time & Space Complexity
- **Time Complexity:** `O(1)`
- **Space Complexity:** `O(1)`
---

### 💻 Code
```python
x = int(input())
y = int(input())

# Perform addition
p = x + y

# Perform subtraction
q = x - y

# Perform multiplication
r = x * y

# Perform integer division
s = x // y

# Perform modulo operation
t = x % y

print(p, q, r, s, t)
