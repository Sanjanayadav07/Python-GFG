# 🧾 Python Input & Output Program

This program demonstrates basic input and output operations in Python.

## 📌 Features
- Takes string input
- Takes integer input and adds `10`
- Takes float input and multiplies by `10`
- Prints all results

## 🧑‍💻 Code

```python
# User function Template for python3

s = input()          # string input
n = int(input())     # integer input
f = float(input())   # float input

print(s)
print(n + 10)
print(f * 10)
